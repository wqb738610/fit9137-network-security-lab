# FIT9137 Network Security Lab

This repository archives a CORE-based network security configuration project involving static routing, DHCP, and Linux iptables firewall rules.

## Project Type

Network configuration lab, CORE topology, static routing, DHCP, firewall policy design, connectivity validation.

## My Contribution

- Configured a simulated multi-router network topology in CORE.
- Added static routes across routers and network segments.
- Configured DHCP behaviour for a client subnet, including address pool, gateway, and DNS settings.
- Built an iptables firewall policy on R3 with default DROP posture, established/related traffic handling, DMZ service allowances, and source/interface-bound forwarding rules.
- Documented routing, DHCP, firewall design, and validation tests in a technical report.

## Repository Contents

- `submission/network-topology.imn` - CORE topology/configuration file.
- `submission/configuration-notes.md` - public summary of the configuration work.

## Scope Note

This public version keeps the CORE topology/configuration file and removes the original submission report. It should be described as CORE routing, DHCP, and iptables configuration, not as a production enterprise network deployment.
